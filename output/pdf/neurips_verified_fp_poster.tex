\txt{32}{22}{26}{\sect{02}{Check arithmetic correctness}
\textcolor{teal}{\textbf{Check B: does it match the specification?}}\par\vspace{.35cm}
\textbf{Strategy:} use exhaustive SMT checks where tractable; invest in structured Lean proofs for difficult operations.\par\vspace{.35cm}
\para{Tier 1: exhaustive SMT}{Multiplier-free FP32 operators and binary BF16 arithmetic are checked against SMT-LIB floating-point semantics.}
\para{Tier 2: structured Lean}{For FP32 multiply and FMA, lift bit patterns to algebraic values and prove rounding against a value-level RNE specification.}
\textcolor{teal}{\textbf{Why it scales:}} reason about one natural-number multiplication, not a bit-blasted $24\!\times\!24$ multiplier.\par\vspace{.35cm}
\smallfont\textbf{Contract:} two-state values; static RNE; no dynamic rounding modes or status flags. Lean correctness statements retain their stated premises.}

\txt{3}{61.7}{26}{\color{white}\smallfont\textbf{Narrow FMA is not always narrow RNE.}\par\vspace{.25cm}
BF16 and E5M2 FMA implement characterized FP32-accumulating fusion, followed by narrowing. E4M3 FMA is correctly rounded outright.\par\vspace{.45cm}
\textbf{General block-dot bound proved\textsuperscript{*}.}\par\vspace{.25cm}
For 1--32 finite elements in five low-precision formats, with valid E8M0 scales, finite outputs obey a Lean error bound including both scale roundings and underflow. Nonfinite outputs have an overflow-stage witness.\par\vspace{.3cm}
Native proof evaluation and compiler/RTL correspondence remain trusted.}

\textbf{All-input compositional SMT comparison completed.} It trusts solver verdicts, FP-to-BV lowering and encoding/cut composition; it is not a new Lean end-to-end theorem.\par\vspace{.35cm}
\textbf{Carcara checking adds independent SMT evidence.} Partial certification of the additional FMA SMT comparison is not a missing step in the Lean FMA proof. The frozen snapshot has 28 accepted certificates (10 support + 18 finite partitions).}

\txt{3}{72.7}{26}{\sect{06}{What the checks caught}
\smallfont\textbf{SymbiYosys all-cycles proof\textsuperscript{*}.} RTL vs. combinational reference: FMA6 (reset high), FMA7 (low); block-dot E2M1, $N=3$ (high), E5M2, $N=3$ or $32$ (low). After initial reset: synchronous reset/internal fill-valid; no stalls or external handshake. 30 injected faults caught.\par\vspace{.2cm}
\textbf{Known Z3 FMA bug reproduced.} Z3 4.15.4 allowed the wrong adjacent result. Exact arithmetic, Bitwuzla and corrected Z3 agreed; this was a known upstream defect.\par\vspace{.2cm}
\textbf{Carcara bug fixed upstream\textsuperscript{*}.} Empty OR/AND identities corrected to false/true (\href{https://github.com/ufmg-smite/carcara/commit/ed1250fa458bf9a37612333624c9aa3dd8de11a5}{18 Nov 2026}). Our local fix rejects an invalid-proof probe; earlier certificates were rechecked.}
\txt{32}{72.7}{26}{\sect{07}{What users can prove}
\smallfont\textbf{FP8 narrowing without overflow.} Under the default E4M3 profile (overflow $\to$ NaN), adding two inputs in $[-128,128]$ then narrowing is \textbf{PROVED} never NaN.\par\vspace{.3cm}
Remove the range assumptions: \textbf{REFUTED}, with counterexample $-448 + (-52)$.\par\vspace{.3cm}
\textbf{Block-dot error bounded\textsuperscript{*}.} For 1--32 finite elements (five formats, valid E8M0 scales), Lean bounds error from the exact scaled dot product for finite outputs, including accumulation, scale rounding and underflow; nonfinite outputs have an overflow-stage witness.}
