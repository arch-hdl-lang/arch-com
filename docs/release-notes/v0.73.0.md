# ARCH v0.73.0

A feature and correctness release. It adds one language feature,
`shared(when EXPR) function`, which turns operator sharing on or off per
parameter. It also changes package and domain scoping (maintainer-approved),
tightens clock-domain-crossing and multi-driver checks, and fixes several
SystemVerilog miscompiles.

## Language

- **`shared(when EXPR) function` (#1088).** A module-local `shared function`
  can now be shared conditionally. `EXPR` must be a 1-bit constant expression
  over the enclosing module's params and literals. One SV text serves every
  parameter value: each bound call site becomes
  `((EXPR) ? __shared_<SVNAME>_out : <SVNAME>(args))`, and synthesis folds the
  select. After folding, `EXPR = 1` gives exactly the plain-`shared` netlist and
  `EXPR = 0` exactly the plain-`function` netlist; a Yosys test checks both.
  The intended use is one source with per-target synthesis options, e.g.
  shared on an area-bound ASIC flow and inlined on an FPGA flow. Plain
  `shared function` is unchanged. The spec now also gives the real harness
  signal names, which are type-mangled (`__shared_MacRes_b_16_b_16_34_out`),
  not `__shared_<FN>_out`.
- **Package and domain scoping (#1062, maintainer-approved).**
  - The built-in `SysDomain` is never hidden by a package that declares it.
  - Members of a package declared in the same file are visible without `use`
    (spec §3.12, "file-wide"). This reverses part of #745.
  - A package member used from another file still needs `use`.
  - `domain SysDomain freq_mhz: N` is now applied; it used to be dropped
    silently, so multi-clock sim got no tick for the domain.
  - Two different `freq_mhz` values for one domain are now a compile error.
  - An undeclared `Clock<FooDomain>` is now specified (§5.1) as an implicit
    domain with no attributes.
- **Package visibility enforced for aliases and port types (#1065).** Package
  aliases and the port types of non-module constructs no longer leak into
  files that don't `use` the package (spec §29.2). **Designs that relied on the
  leak now fail `arch check` with `undefined name`; add the missing `use`.**

## Emitted SystemVerilog changes

If your design uses any of the constructs below, its generated SV changes.
Regenerate and re-verify it.

- **`fifo` with a non-power-of-two `DEPTH` (#1061).** The single-clock sync
  (latency 0) and latency-1 FWFT variants assumed a power-of-two depth, with
  pointers wrapping at `2^PTR_W`, so the SV diverged from `arch sim` and
  formal. They now use modular pointers.
- **`synchronizer kind handshake` / `kind pulse` honor an async reset
  (#1051).** They emitted a synchronous reset for a `Reset<Async, _>` port;
  `kind ff` and `kind gray` were already correct.
- **Bare enum-variant references (#1081, closes #1031).** `mode <= Run` /
  `mode == Run` (short name instead of `Enum::Variant`) passed `arch check` but
  miscompiled in both sim and SV. Both backends now resolve it.
- **`assert` inside a param-ranged `generate_for` is no longer dropped
  (#1077, closes #1076).** The loop was kept as an SV genvar loop and every
  `assert property` vanished. Such loops are now unrolled.
- **`generate_for` holding only `comb` or only `seq` items (#1072, closes
  #1071)** no longer panics `arch build`; it is unrolled.

## New compile errors (previously accepted)

- **Clock-domain crossing checks are now per target (#1055, #1059, #1060,
  #1066).** The comb->seq and `inst`-boundary checks attribute fan-in per
  assigned target and per child clock port, not per block or per domain. A
  module-scope `let` read directly by a foreign-domain `seq` is now caught. The
  `inst`-boundary verdict is deterministic across runs.
- **Multi-driver detection (#1067 closes #1063, #1070 for #929).** An `inst`
  output colliding with a `seq`/`latch`/`let` driver, or a multi-driver through
  a `generate_for` kept as a genvar loop, is now an error. Verilator already
  rejected the emitted SV.
- **Undeclared bare `comb` target (#1080, #1074 case 3).** Assigning a name
  that isn't declared used to emit a 1-bit implicit net; it is now a
  compile error.

## Separate compilation

- **`.archi` stubs carry the `use` lines their port and param types need
  (#1087, closes #1086).** Without them, a parent instantiating a module
  through a stub with package-typed ports failed after #1065.

## Tooling

- `arch --version` provenance no longer forces a rebuild after `git gc`, and
  the build script never rewrites the git index (#1085).
- Pre-push hooks block unformatted Rust (#1083) and unregistered testbenches
  (#1084).
- Nightly portability is green again (#1054); the ThreadMm2s Icarus
  improvement is recorded (#1075).
