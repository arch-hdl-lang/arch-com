# ARCH v0.74.1

A patch release for one 0.74.0 emission regression. It has no language or
checking changes.

## Emitted SystemVerilog changes

- **The carry cast is dropped where it is provably redundant (#1099).**
  - **What 0.74.0 did:** it wrapped every non-constant `+`, `-` and `*` in a
    size cast so SV keeps the carry (#1095). As an index, that cast is wider
    than the index needs. `v[6'(30 - cnt)]` into a 32-entry vector makes
    Verilator report `WIDTHTRUNC`, which fails lint gates such as arch-ibex's
    SoC lint.
  - **When the cast is now omitted:**
    - for `+` and `*` with a bare decimal literal and a narrow unsigned
      operand (the value is identical in any context);
    - for `lit - x` directly as an index whenever `2^(W-1) >= N`.
  - **Effect on output:** these spellings return to 0.73.0's form
    (`v[30 - cnt]`, `8'(count_r + 1)`).
  - **Unchanged:** subtraction keeps its cast everywhere else, so #1095's
    comparison fix (ARCH wraps `0 - 1` to `2^W - 1`, SV to `2^32 - 1`) stands.
  - **Verification:** arch-ibex's flattened netlist under 0.74.1 is formally
    equivalent (Yosys, 31,562 of 31,562 cells) to the 0.73.0 one.
