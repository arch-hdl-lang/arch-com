# ARCH v0.72.6

A correctness release: two reset miscompiles in the SV emitter, one in the
simulator, plus a non-compiling sim case, `fsm` support in `arch formal`, and
deterministic comb-loop diagnostics. There are no syntax or language-semantics
changes. The reset fixes make the emitter do what a `Reset<Kind, Level>` port
already meant, and `arch sim` always did.

## Emitted SystemVerilog changes

If your design uses any of the constructs below, its generated SV changes.
Regenerate and re-verify it.

- **`pipe_reg` honors reset kind and polarity (#1043).** The module-scope
  `pipe_reg NAME: SRC stages N;` form emitted `always_ff @(posedge clk)` +
  `if (rst)` for every reset port. On `Reset<Async, Low>` that inverted the
  reset: the chain was cleared every normal cycle and shifted only while reset
  was asserted, so the delay line read as a constant zero. It now emits the
  correct sensitivity list and polarity for all four `Kind x Level`
  combinations.
- **`guard`-contract shadow flop matches the design's reset kind (#1043).**
  `_<reg>_written` had the right polarity but always used a synchronous
  sensitivity list.
- **Auto-generated SVA regions carry a scoped `SYNCASYNCNET` waiver (#1043).**
  Verilator counts a concurrent assertion's `disable iff (<reset>)` as a
  synchronous use of the reset net. Each auto-SVA `translate_off` region now
  opens with `/* verilator lint_off SYNCASYNCNET */` and closes with the
  matching `lint_on`. A design that really mixes sync and async resets is still
  reported. Verilator drops a leaf's `lint_off` once the leaf is inlined, so a
  full-SoC lint can still need a project-level waiver.
- **`linklist` honors reset kind and polarity (#1044).** The free-list, head,
  tail and length reset used the same hard-coded form. On `Reset<Async, Low>`
  it re-initialized the free list every normal cycle and never on reset. Same
  bug class as `pipe_reg`, and fixed through the same shared reset helpers.

## Simulator

- **`linklist` sim resolves clock and reset by type (#1047, closes #1046).**
  The C++ model hard-coded a member named `rst`. A reset port named anything
  else (e.g. `rst_n`) produced a phantom, never-driven `rst`, and the reset
  logic read that instead of the real port.
- **Whole-`Vec` RHS into a scalar LHS (#1023, arch#1019 defect #3).**
  `y = wi;` with `wi: Vec<Bool, 4>` and `y: UInt<4>` used to emit C++ that did
  not compile. It is now packed element-by-element, matching the SV.

## Formal and diagnostics

- **`arch formal` accepts `fsm` (#1039).** An `fsm` given as the top, or
  instantiated in a hierarchical design, used to fail with "module not found".
  It is now lowered to an equivalent module before SMT encoding.
- **Deterministic comb-loop diagnostics (#1041, closes #756).** The
  whole-design combinational-cycle warning listed its nodes in a
  hash-seed-dependent order. The same input now always prints the same cycle.

## Documentation

- The spec no longer documents the `crossing ... end crossing` block, which
  was never implemented. Clock-domain crossings use `synchronizer` (section 8.3)
  or a dual-clock `fifo` (section 8.2) (#1035).
- A spec citation anchor in the tests (#1038) and a header comment in the
  `fsm` formal lowering (#1042) now match the current text.
