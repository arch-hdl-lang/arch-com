# ARCH v0.74.0

A correctness release. It adds new compile-time checks at `inst` boundaries
and for thread resets. One maintainer-approved language rule is new, and it
fixes 44 further defects across the compiler, simulator and formal backends.
**Some designs that compiled on 0.73.0 are now rejected.** Each such error
points at a real mismatch and says how to fix it.

## New compile errors (previously accepted)

- **Explicit `inst` connections are type-checked (#1092, closes #737 and
  #738).** Width, signedness, `Vec` length and reset kind/polarity must match
  the port, evaluated with the inst's `param` overrides. This matches spec
  §353 ("every ... port connection ... is width-checked") and the rules
  `auto;` already applied.
  - Convert widths explicitly (`d <- x.zext<8>();`).
  - Re-type a reset explicitly (`rst <- rst_n as Reset<Sync, High>;`).
  - Not errors: a clock of another domain (it rebinds the instance's domain,
    spec "Clock domain rebind is not a crossing"), and compile-time constants
    such as `1` or `HEAD_DIM`, which take the port's width.
- **A thread's reset level must match its reset port (#1093, language rule).**
  `thread T on clk rising, rst low` on a `Reset<_, High>` port is an error:
  either the clause or the port declaration is wrong. There is no override
  in the clause; re-type the reset at the parent's inst connection instead.
  This applies to every thread form, including TLM target threads, which used
  to ignore the clause silently.
- **Compiler-generated instances are checked too (#1097).** This covers the
  thread/TLM `_<Mod>_threads` and `_arb_*` instances. Lowering now wires them
  type-correctly, so a mismatch reported there is a compiler bug; please
  report it.
- **Ternary conditions and both arms are validated (#1095).** So are match
  arms and incomplete `##` delay diagnostics (#1096).

## Emitted SystemVerilog changes

If your design uses any of the constructs below, its generated SV changes.
Regenerate and re-verify it.

- **Thread lock arbiters take the module's reset kind (#1094, closes
  #1091).** On a `Reset<Sync>` design the synthesized `_arb_*` emitted async
  flops (`posedge clk or posedge rst`) beside synchronous thread logic. It now
  matches the `_threads` module.
- **From #1095:**
  - arithmetic carries and `Vec` reduction grouping are retained, with
    explicit arithmetic sizing;
  - counter MAX, Gray sequences and one-hot rotation are corrected;
  - reset specialization polarity, conditional `.archi` parameters, nested
    thread loop bounds and one-shot terminal actions are preserved.
- **From #1096:**
  - write-first RAM write enables and handshake destination capture are fixed;
  - synchronizer model naming and edge scheduling are fixed;
  - bus alias/wire parameter propagation and generated-instance
    specialization/naming are fixed;
  - `inside` precedence is fixed, and the spec now documents it.

## Simulator and formal

- Native-sim widths and wide reductions are preserved, as are module-local
  native-function scope and FIFO expression depths (#1095, #1096).
- Formal: unsigned negation, full shift counts and source-order assignment
  priority are corrected (#1095, #1096).
- Floating point:
  - E8M0 conversion through ternaries is fixed (#1095);
  - float negation and conversion, and top-binade block quantization, are
    fixed (#1096).
- Python (`--pybind`): signed signal writes and `seconds` time units are fixed
  (#1096).

## Parsing and separate compilation

- Valid block comments and `ram ... init: none` are accepted (#1095).
- Imports are resolved relative to each source file, and only the preferred
  dependency provider is selected (#1095).
- `.archi` stubs carry `use` lines for package-param-typed ports such as
  `UInt<WIDTH>` (#1090, completes #1087).
